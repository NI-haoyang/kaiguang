# 报名提交材料（可直接粘贴）

**作品名**：开机第一天 · 新电脑开荒

**一句话**：新笔记本到手，先验它是不是真的全新，再看清里面装了什么，然后按你的用途替你收拾干净——每改一处都能一键退回去。

**交互演示（点开就能玩，执行是模拟的，不碰你的电脑）**：https://ni-haoyang.github.io/kaiguang/docs/agent-demo.html

**在线 Demo（只读版）**：https://ni-haoyang.github.io/kaiguang/

**桌面版（能真的动手，能真的撤销）**：[Releases v0.2.7](https://github.com/NI-haoyang/kaiguang/releases) 下载 zip（约 113 MB，含运行时，不用装 Node、不用联网），解压后双击 `开机第一天.exe`。

**代码仓库**：https://github.com/NI-haoyang/kaiguang

**三十秒怎么看出它有用**：
打开交互演示，点「学习为主」→「留 WPS」→ 看到动作卡片 → 改主意就打「留 Office」，卡片当场整组换掉 → 打「迈克菲能删吗」，它用这次体检的数据回答 → 点执行，逐条变绿 → 点「全部撤销」，三秒回到原样。
桌面版更直接：双击 `开机第一天.exe` → 自动体检 20 秒 → 开荒指数 70 分，左边列出「1 处要处理、其余可选」→ 中间问两句（这台主要干嘛、办公套件留哪个）→ 列出卡片，每张写明为什么、影响什么、能不能退 → 关自启点执行，0.8 秒逐条变绿；重复软件只把你带到设置页，不代劳 → 点「全部撤销」，3 秒回到原样。
一句话总结：**同类工具只给清单，我们负责执行，并且保证能退。**

**AI 用在哪（以及为什么不是「套壳」）**：
- AI 负责两件事：**解释每一张动作卡**（这是什么、关掉会怎样、能不能退），以及**回答追问**（「TX Mascot 是干什么的」「迈克菲能删吗」）。它读的是这台机器的真实数据（79 个软件、10 个自启、23 个服务），再叠加一份 20 多条的内置知识库。
- **动作清单由规则引擎挑，模型不参与执行**。命中体检规则才出卡；模型只读摘要、只输出纯文本，既不写命令，也不产出动作。
- 所以模型说错，最多是**解释不准**，不会误操作；真正动手的每一步都有原值记录和撤销。这是答辩要讲的核心：我们假设 AI 会犯错，所以不让它碰执行。
- 没有 key 也能完整跑：常见组件由内置知识库回答，体检、执行、撤销一个不少；填了 key，才能解释清单外的软件。Release 里**不含任何 key**，现场演示机由我们自己配置。
- 每天有调用上限（默认 400 次），断网 / key 失效 / 额度用完都会静默回落到本地规则，现场不怕没网。

**作品边界（我们主动没做的）**：
- 不卸驱动、不改 BIOS、不碰分区、不删系统组件。
- **不代卸 OEM 预装软件**：这类软件没有静默卸载、也装不回，自动卸了「撤销」就是空话；我们只带路到设置页，最后一下你自己点。
- 需要管理员权限的事（改服务启动类型、开防火墙）不代劳，只把你带到设置页，最后一下你自己点；整机级的开机自启会弹一次 UAC，你同意才动。
- 没有你点击，不执行任何动作；每个动作执行前先记原值，撤销就是把原值写回去。
- 本地服务只监听 `127.0.0.1`，而且每次启动生成一次性口令、所有接口都要带；别的网页拿不到口令，就没法替你按「执行」。
- 不承诺「一键变快」，只承诺「改了什么你能看见，改错了你能退回」。

**技术栈**：Electron 33 套壳（约 268 MB 目录，自带运行时）+ 原生 Node HTTP 服务（127.0.0.1 随机端口）+ PowerShell 只读采集 + 注册表 StartupApproved 关自启 / 撤销。没有云服务，数据不出本机。
