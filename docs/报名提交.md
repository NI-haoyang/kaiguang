# 报名提交材料（可直接粘贴）

**作品名**：开机第一天 · 新电脑开荒

**一句话**：新笔记本到手，先验它是不是真的全新，再看清里面装了什么，最后给一张按「今天 / 这周 / 以后」排好的开荒单——不替你改系统，只把这台机器讲明白。

**在线 Demo**：https://ni-haoyang.github.io/kaiguang/

**代码仓库**：https://github.com/NI-haoyang/kaiguang

**三十秒怎么看出它有用**：打开上面链接，点「载入示例（刚开箱）」看到 79 分和「看起来就是全新机」；再点「载入示例（已用 79 天）」看到 55 分和「这个不像刚拆封的机器」。同一台机器，只换了数据，结论完全相反。

**在你自己的电脑上跑**：下载仓库，双击 `双击我.bat`，约 20 秒，桌面出现 `我的电脑体检报告-日期.html`。断网也能看，因为这只是一个文件。

**AI 用在哪**：判断由本地规则引擎做（可复现、离线、不联网）；AI 负责把报告翻译成「现在最该做的一件事」和解释「这条为什么对你有影响」——同样的 23 个自启服务，对游戏本和办公本该关的不是同一批。去掉 AI 作品仍然可用，但会退化成一张清单；训练营期间会把 AI 前移到「识别规则库没覆盖的软件是什么、该留还是该卸」。

**作品边界（我们主动没做的）**：不自动卸载、不自动改注册表、不刷 BIOS、不代装系统。生成的脚本每一行默认都是注释掉的，用户逐条取消注释才执行。
