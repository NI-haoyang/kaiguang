# 报名提交材料（可直接粘贴）

**作品名**：小白助手 · 新电脑开荒

**一句话**：新笔记本到手，先验它是不是真的全新，再看清里面装了什么，然后按你的用途替你收拾干净——每改一处都能一键退回去。

**交互演示（点开就能玩，执行是模拟的，不碰你的电脑）**：https://ni-haoyang.github.io/kaiguang/docs/agent-demo.html

**在线 Demo（只读版）**：https://ni-haoyang.github.io/kaiguang/

**桌面版（能真的动手，能真的撤销）**：[Releases v0.2.17](https://github.com/NI-haoyang/kaiguang/releases) 下载 zip（约 113 MB，含运行时，不用装 Node、不用联网），解压后双击 `小白助手.exe`。

**代码仓库**：https://github.com/NI-haoyang/kaiguang

**三十秒怎么看出它有用**：
双击 `小白助手.exe` → 自动体检 20 秒 → 开荒指数 70 分，左边列出「1 处要处理、其余可选」→ 中间直接打「打游戏」，AI 先给一套游戏方案，再列出 4–5 张动作卡（防火墙、关装饰自启、重复软件带路），每张写明为什么、影响什么、能不能退 → 说「就按这个来」，方案不变、勾选保留 → 点执行，0.8 秒逐条变绿；重复软件只把你带到设置页，不代劳 → 点「全部撤销」，3 秒回到原样。新电脑缺微信/网易云，点左边「装软件」，勾一下装好，日志里同样能撤销。想看 C / D 盘被谁占了，点左边「磁盘空间」，几秒钟出缓存、临时文件、回收站和目录占用；扫完可以勾选清临时文件和回收站（二次确认，删了退不回）；其他缓存交给「打开存储感知」。右栏顶部一直显示本机状态：CPU 使用率和近似频率、内存、C / D 剩余、GPU 温度和 ACPI 热区温度；只读，不装驱动。关窗口它不退出，缩在托盘里；开机自启默认开，每周自己体检一次，和上周对比，窗口关着就发系统通知。

静态交互演示只演示卡片、执行和撤销的视觉，对话流程以桌面版为准。
一句话总结：**同类工具只给清单，我们负责执行，并且保证能退。**

**AI 用在哪（以及为什么不是「套壳」）**：
- AI 负责**对话和方案**：用户说「打游戏」「剪视频」「写代码」「学习」，它直接按用途给一套具体方案（每条说清为什么、影响什么、能不能退），再从服务端给的候选动作里挑编号；追问「TX Mascot 是干什么的」「迈克菲能删吗」也由它结合这台机器的真实数据和 20 多条内置知识回答。
- **候选动作由体检数据生成，执行仍要人点头**。模型拿不到命令，也不能拼 target：它只能返回候选编号（最多 5 个），页面把它映射成卡片；真正执行要你勾选后点「执行选中的 N 项」。
- 所以模型说错，最多是**选错一条候选**，不会命令注入、不会自己动手；真正动手的每一步都有原值记录和撤销。这是答辩要讲的核心：我们假设 AI 会犯错，所以不让它碰执行。
- 没有 key 也能完整跑：`localPlan` 按用途给通用方案，常见组件由内置知识库回答，体检、执行、撤销一个不少；Release 里**不含任何 key**，现场演示机由我们自己配置。
- 每天有调用上限（默认 400 次），断网 / key 失效 / 额度用完都会静默回落到本地规则，现场不怕没网。

**作品边界（我们主动没做的）**：
- 不卸驱动、不改 BIOS、不碰分区、不删系统组件、**不删用户文件**；清理只做 7 天前的临时文件和回收站，二次确认、不可撤销。
- **装软件只装内置清单**：微信、QQ、腾讯会议、WPS、网易云、Chrome、7-Zip、Everything、VS Code、Git 十个，包 id 写死在代码里，不接受任意下载链接；装完可撤销（卸载刚装的），winget 退不干净的会再用安装包自带卸载器补一次。
- **不代卸 OEM 预装软件**：这类软件没有静默卸载、也装不回，自动卸了「撤销」就是空话；我们只带路到设置页，最后一下你自己点。
- 需要管理员权限的事（改服务启动类型、开防火墙）不代劳，只把你带到设置页，最后一下你自己点；整机级的开机自启会弹一次 UAC，你同意才动。
- 没有你点击，不执行任何动作；每个动作执行前先记原值，撤销就是把原值写回去。
- 本地服务只监听 `127.0.0.1`，而且每次启动生成一次性口令、所有接口都要带；别的网页拿不到口令，就没法替你按「执行」。
- 不承诺「一键变快」，只承诺「改了什么你能看见，改错了你能退回」。

**技术栈**：Electron 33 套壳（约 268 MB 目录，自带运行时）+ 原生 Node HTTP 服务（127.0.0.1 随机端口）+ PowerShell 只读采集 + Node 只读扫盘 / 安全清理 + Node 只读硬件遥测（CPU / 内存 / NVIDIA GPU / ACPI 热区）+ 注册表 StartupApproved 关自启 / 撤销。没有云服务，数据不出本机。
