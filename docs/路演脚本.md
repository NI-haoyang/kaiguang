# 路演脚本（11.29）

## 90 秒版

> 我先问一句：在座谁的笔记本，是买回来就直接用的？——我也是。
>
> 直到我打开「已安装应用」，发现自己这台天选上有 **70 个软件**：14 个华硕组件、3 套安全软件、4 个浏览器、5 个视频客户端、23 个开机就启动的服务。我一件都不敢删，因为我不知道哪个删了会出事。
>
> 网上有两种答案：一种是「新电脑必装 50 款软件」，它不知道我电脑里已经有什么；另一种是一串命令，让我复制粘贴，我也不知道它在干嘛。
>
> 所以我做了「开机第一天」：它先读一份**只读**的体检报告——不写注册表、不装东西、不联网；然后把 70 个陌生名字翻成人话，比如它会告诉你「Defender 显示关闭是正常的，你装了火绒，它自动让位了，不是中毒」；最后给你一张按今天、这周、以后排好的开荒单，和一份**每一行都带井号**的脚本——你想执行哪条，自己删井号。
>
> 我们不替你改系统，我们替你搞明白。这就是开机第一天。

## 3 分钟版补充段落

**（演示）** 现在现场跑一次采集，三秒钟。把文件拖进来——看，开荒指数 61。它先说最要紧的两件事：三套安全软件在互相扫描，防火墙是关的。往下是那些「知道就行」的：华硕 14 个组件里有 7 个是纯装饰。再往下是「没问题」的：C 盘还剩 48%，不用动。

**（差异化）** 我们刻意不做「一键优化」。因为这个人群真正缺的不是工具，是判断力。一键优化的下一步，永远是「我点了之后电脑黑屏了」。

**（当天增量）** 今天加的是解释能力：接上模型之后，它会根据你的机器说「先做这一件，因为……」，而不是给你一张 20 项的清单。

## 可能被问到的

**Q：这不就是清理软件吗？**
A：清理软件从「清理」出发，我们从「你已经有的是什么」出发。而且我们不执行，只解释——这是故意的。

**Q：安全吗？会不会误删？**
A：采集脚本只读；生成的脚本全部是注释，一行都不会自己跑；页面明说「我们不替你改系统」。真正执行那一刻的人是你。

**Q：真有人用吗？**
A：今天现场我请三位同学跑了真机（口播具体结果）。开学季、宿舍、二手电脑，这个场景每年发生两次。

**Q：AI 在哪？**
A：两层。规则层负责「准确」（哪些服务是华硕的、哪些是运行库，不能猜）；模型层负责「说人话」——把结论组织成「你现在最该做哪一件」。规则保底，模型加分。
