开机第一天 · 使用说明
=====================

这是什么
  给新电脑用的只读体检 + 开荒单。
  读一遍这台机器装了什么、开机自启了什么，然后告诉你哪些该收拾。
  全程不联网、不装软件、不改设置。

怎么用（最省事：一个 exe，105 KB，不用装任何东西）
  1. 双击 开机第一天.exe
  2. 小窗口转十几秒 → 浏览器自己弹出报告
  3. 想看离线文件，点窗口里的「存一份 html」
  第一次运行 Windows 可能弹「Windows 已保护你的电脑」，
  点「更多信息」→「仍要运行」。没签名的小工具都会这样，
  源码就在 exe\KaiguangApp.cs，可以自己编译一份。

怎么用（推荐：不需要联网，也不需要装 Node）
  1. 解压这个文件夹到任意位置（比如桌面）
  2. 双击 双击我.bat
  3. 等 20–30 秒，桌面会出现 我的电脑体检报告-日期时间.html
  4. 双击那个 html 就能看

怎么用（让浏览器自己弹出的版本，需要 Node.js）
  1. 先装 Node.js：https://nodejs.org/ （装完不用重启）
  2. 双击 一键运行.bat
  3. 黑窗口里跑完，浏览器会自己打开，报告直接显示

  看到的报告和上一种方式完全一样，只是不用手动拖文件。

几个入口分别干什么
  开机第一天.exe 采集 + 开网页 + 可存 html  什么都不用装
  双击我.bat     采集 + 生成 html + 打开    不需要 Node
  一键运行.bat   采集 + 开本地网页         需要 Node
  打开网页.bat   只打开网页，不采集        不需要 Node

常见问题
  Q: 杀毒软件报警？
  A: 脚本用 PowerShell 和 WMI 读硬件信息，部分国产杀软会提示。
     源码是纯文本，右键用记事本打开就能逐行看完。

  Q: 双击 bat 一闪而过？
  A: 说明 PowerShell 没跑起来。在文件夹里按住 Shift 右键 →
     「在此处打开 PowerShell 窗口」，然后运行：
     powershell -NoProfile -ExecutionPolicy Bypass -File .\collect.ps1
     看它报什么错。

  Q: 报告里我的用户名显示成 * ？
  A: 故意的。脚本会把 C:\Users\你的名字 替换成 *，
     这样报告可以放心发给别人看。

  Q: 能改我的电脑吗？
  A: 不能。采集脚本里没有一条写入命令。开荒单里的命令
     默认全被注释掉了，你自己决定要不要执行。

  Q: 报告是死的还是能再看？
  A: 生成的那个 html 是独立文件，断网、换台电脑、发微信都能打开。
